# 高算力 State 池生产修正

状态：实现及本地验证完成，待 PR 审查。维护者已批准前后端旧接管停用、独立账号卡片、纯 HTTP SSE、新续期调度、逐次日志与手动导入。

具体规则以 docs/conventions/codex-turn-state.md 为准。

## 关键验证

- 动态 SOCKS5H 本地对照：独立连接四次四个出口，连接复用四次同一出口。最终实现使用禁止 keep-alive 的独立 Transport，普通业务不受影响。
- 固定协议：仅 HTTP SSE 获取，metadata 兼容带/不带 codex 前缀，业务 WS 仍逐帧注入。
- 有效期：Fernet 签发时间与网关获取时间中较早的 1 小时期限；30/10 分钟边界、周期轮 25 次及持续模式不封顶。
- 导入：本地检查后携带输入值验证，上游正常完成才允许写入，仅更晚到期的新值替换；原始输入在通用审计中脱敏。
- 数据库：新增事件日志和使用记录长度列，验证分页、7 天保留与批量写入；不修改生产数据。
- UI：每账号独立模型选择、日志分页、导入成功清空输入以及旧设置隐藏。
